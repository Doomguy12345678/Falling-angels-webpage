FALLEN ANGELS WEBSITE

FILES:
index.html       Main landing page
music.html       Music/player page
members.html     Band members page
shows.html       Live shows page
contact.html     Contact form
css/style.css    Entire visual design
js/main.js       Petals, navigation, audio behavior
audio/           Put MP3 files here
images/          Put photos/artwork here

To run:
1. Keep the folder structure intact.
2. Open index.html in a browser.
3. Add your MP3s to audio/.
4. Add your photos to images/.
5. Replace the placeholder member names/roles with the actual band members.

The contact form is visual only until connected to a form service or backend.
